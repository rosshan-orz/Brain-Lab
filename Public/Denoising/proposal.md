# Denoising — 在线降噪

## 研究目标

设计任务特征保真的 EEG 降噪系统——不是"去噪"，是"去噪后任务特征不被破坏"。

## 核心问题

1. **任务特征保真**：传统降噪会破坏 P300、Alpha 阻断、SSVEP ITPC 等任务相关特征
2. **多任务泛化**：单一降噪模型能否适配多种 BCI 任务？
3. **在线推理**：流式处理、延迟 <50ms

## 技术路线

```
数据构建 → 模型设计 → 三维验证 → 在线部署
```

### 阶段 1：数据构建

- 4-session 实验协议：
  1. 静息态（基线）
  2. 伪迹模板采集
  3. "银标准"干净任务数据
  4. 自然污染测试集
- 伪迹注入策略

### 阶段 2：模型设计

- 多尺度 FiLM 条件化降噪器（Phi_spatial）
- 三头输出：降噪信号 + 伪迹检测 + 任务事件检测
- 多尺度卷积分支：瞬态/节律/慢波

### 阶段 3：三维验证框架

| 维度 | 验证内容 | 指标 |
|:---|:---|:---|
| 时域 | P300 波形保真 | 波形相关系数 |
| 宽带 | Alpha 阻断保持 | 功率谱变化 |
| 窄带+相位 | SSVEP ITPC | 相位锁定值 |

### 阶段 4：在线部署

- 流式输入、逐帧输出
- ONNX/TensorRT 边缘部署

## 预期产出

| 产出 | 目标 |
|:---|:---|
| 数据集 | 4-session 标准化采集协议 |
| 降噪模型 | Phi_spatial 多任务条件化降噪器 |
| 验证框架 | 三维特征保真评估体系 |
| 论文 | 1 篇期刊 |

## 下游应用

降噪模型（Phi_spatial）是在线 BCI 系统的预处理模块——为 Foundation Model 提供干净数据。
